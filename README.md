# AVABODH Foundation - NGO Website

![Website Preview](ngo_website_preview.png)

A modern, responsive website built for the **AVABODH Foundation** to showcase their mission, services, and impact. 

## Tech Stack
*   **React** + **Vite** (Ultra-fast performance)
*   **Tailwind CSS** (Modern styling)
*   **Lucide React** (Beautiful icons)

## Features
*   **Professional UI**: Includes a custom-designed interface for NGO needs.
*   **Mobile Friendly**: Optimized for all screen sizes.
*   **Clean Code**: Organized React components.

## Setup
1. npm install
2. npm run dev
